# Borrowed Energy

เกม 2D Top-Down Puzzle Adventure สำหรับวิชา Object-Oriented Programming พัฒนาด้วย Java Swing และ Java2D บน macOS ผู้เล่นควบคุมหุ่นยนต์สำรวจสถานีอวกาศ Helios ในปี 2186 ตามหาแบตเตอรี่ไอออน ต่อวงจร และนำพลังงานไปยังจุดอพยพ

## เปิดเกม

ต้องใช้ **JDK 17 หรือใหม่กว่า** ไม่ต้องติดตั้ง Maven, Gradle หรือไลบรารีเพิ่มเติม

เปิด Terminal ในโฟลเดอร์ `BorrowedEnergy` แล้วรัน:

```sh
./run.command
```

หรือดับเบิลคลิก `run.command` ใน Finder หากเปิดไม่ได้ ให้ใช้ `bash run.command` สคริปต์จะ compile ซอร์ส Java และคัดลอก resources ไปที่ `build/classes` ให้อัตโนมัติ

หากเปิดเกมเวอร์ชันเก่าอยู่ ให้ปิดหน้าต่างเก่าก่อนเปิดใหม่ โค้ดที่แก้ไขได้อยู่ใน `src/main/java` ส่วนไฟล์ `.class` ใน `build` เป็นผลจากการ compile

## สามด่านต่อเนื่อง

แต่ละด่านเป็นแผนที่เต็มหน้าจอขนาด 36 × 20 ช่อง มีผังและปริศนาของตัวเอง เมื่อจบด่านจึงแสดงหน้าสรุปและปลดล็อกด่านถัดไป

| ด่าน | ระดับ | สถานที่และความท้าทาย |
|---|---|---|
| 01 — Orbital Garden | ง่าย | สวนทดลองบนสถานี ต่อวงจรเปิดประตู พร้อมหลบแมลงปีศาจที่บินไปมา |
| 02 — Neon Transit | กลาง | ศูนย์ขนส่งแสงนีออน มีกระแสไฟฟ้ารั่วตามทางและเอเลียนขี่ยานยิงลำแสง |
| 03 — Singularity Vault | ยาก | ห้องนิรภัยเครื่องปฏิกรณ์ ต้องเก็บปืน ต่อวงจร และยิงทำลายหุ่นยนต์ที่ไล่ตามให้ครบ |

แบตเตอรี่เป็นแคปซูลพลังงานอนาคต มีขั้วต่อและแถบพลังงานเรืองแสง แต่ละด่านมีแบตเตอรี่ให้ใช้งานเพียงก้อนเดียว จึงต้องนำกลับมาใช้กับวงจรถัดไป

## การควบคุม

| ปุ่ม | การทำงาน |
|---|---|
| WASD / ลูกศร | เดิน พร้อมการเร่งและผ่อนความเร็ว |
| E | หยิบแบตเตอรี่ เสียบ/ถอดแบตเตอรี่ หมุนรีเลย์ เก็บปืน หรือเก็บ data chip ที่อยู่ใกล้ |
| F ค้าง / คลิกซ้ายค้าง | ยิงเมื่อเก็บปืนแล้ว |
| เมาส์ | เล็งปืน หากยังไม่เล็งด้วยเมาส์จะยิงไปตามทิศที่หัน |
| Esc / P | พักเกม / เล่นต่อ |
| H | เปิดคู่มือการเล่น |
| R | ขอเริ่มด่านปัจจุบันใหม่ ต้องยืนยันก่อน |
| Enter / Space | เริ่มเกม ยืนยันเมนู หรือไปด่านถัดไปหลังผ่านด่านแล้ว |

ใช้เมาส์คลิกปุ่มเมนูได้ เมื่อเปลี่ยนไปใช้หน้าต่างอื่นเกมจะพักอัตโนมัติ

## วิธีผ่านด่าน

1. สำรวจและหาแบตเตอรี่ไอออน เดินเข้าใกล้แล้วกด `E`
2. หมุนลูกศรใหญ่ของรีเลย์ให้ตรงกับเครื่องหมายทิศทางเล็กบนอุปกรณ์
3. เสียบแบตเตอรี่ที่ช่องเสียบของวงจร แล้วรอให้ชาร์จครบ ประตูที่เปิดสำเร็จจะเปิดค้าง
4. ถอดแบตเตอรี่กลับไปใช้กับวงจรถัดไป จนวงจรทุกวงของด่านทำงาน
5. เมื่อทุกวงจรทำงาน ให้เดินไปยังแท่น **EXIT** ที่มุมขวาล่างของแผนที่ ระบบจะเรียกแบตเตอรี่กลับอัตโนมัติ แม้ยังเสียบอยู่ในช่องสุดท้าย
6. หน้าสรุปจะแสดงเมื่ออพยพสำเร็จ กด Enter หรือปุ่ม Continue เพื่อไปด่านถัดไป เมื่อจบด่านที่สามจะขึ้น **GAME COMPLETE** พร้อมสถิติและค้างที่หน้าจบเกม โดยไม่วนกลับไปด่านแรก กด Enter หรือ Space แล้วจะไม่เริ่มรอบใหม่ คลิก **RETURN HOME** เพื่อกลับหน้าแรกได้ โดยจะเริ่มรอบใหม่เมื่อกด **START EXPEDITION** เท่านั้น

หากถอดแบตเตอรี่ก่อนวงจรชาร์จเต็ม ประจุของวงจรที่ยังไม่สำเร็จจะค่อย ๆ ลดลง

**ด่าน 3:** ต้องเก็บปืนด้วย `E` และทำลายหุ่นยนต์ไล่ตามทุกตัวด้วย `F` หรือคลิกซ้ายค้าง จึงจะใช้ EXIT ได้ การเก็บ data chip เป็นกิจกรรมเสริมและไม่ใช่เงื่อนไขผ่านด่าน

### ชีวิตและการเริ่มใหม่

เริ่มแต่ละด่านด้วย **5 ชีวิต** อุปสรรคแต่ละครั้งลด 1 ชีวิต มีช่วงคุ้มกันสั้น ๆ หลังโดนเพื่อไม่ให้ชีวิตลดซ้ำทุกเฟรม การชนศัตรูหรือโดนลำแสงไม่รีเซ็ตปริศนาทันที ส่วนการตกช่องว่างจะเสีย 1 ชีวิตแล้วเรียกกลับ checkpoint เพราะเดินต่อบนช่องว่างไม่ได้

เมื่อชีวิตเหลือ 0 เกมจะหยุดที่หน้าพ่ายแพ้ กด Enter หรือปุ่มลองใหม่เพื่อเริ่ม **ด่านเดิม** ด้วย 5 ชีวิต วงจร ศัตรู และของเก็บของด่านนั้นจะกลับสู่จุดเริ่มต้น แต่ด่านก่อนหน้าที่ผ่านแล้วยังคงผ่านอยู่

### อุปสรรคและของเสริม

- **แมลงปีศาจ:** บินลาดตระเวนในด่าน 1 ให้หลบตัวแมลง
- **ไฟฟ้ารั่ว:** พื้นที่ไฟฟ้าในด่าน 2 มีช่วงเตือนและช่วงปล่อยกระแส รอให้ปลอดภัยก่อนข้าม
- **เอเลียนขี่ยาน:** ในด่าน 2 จะเตือน 2 วินาที โดยล็อกแนวเล็งก่อนยิง 0.6 วินาทีให้เดินหลบ ลำแสงทำงาน 0.75 วินาที แล้วพักยิง 5.5 วินาที ให้หลบแนวลำแสงและตัวยาน
- **หุ่นยนต์ไล่ตาม:** ในด่าน 3 จะหาเส้นทางเข้าหาผู้เล่น หลบและใช้ปืนทำลาย ตรวจจำนวนศัตรูที่เหลือใน HUD
- **เลเซอร์:** สีเหลืองเป็นช่วงเตือน ก่อนยิงลำแสงอันตราย รอให้ดับจึงข้าม
- **ช่องว่างในพื้น:** ตกแล้วเสีย 1 ชีวิตและถูกเรียกกลับจุดปลอดภัย
- **Checkpoint:** เดินเข้าวงแหวนเพื่อบันทึกจุดเรียกกลับ ระหว่างด่านไม่ต้องกด E
- **Data chips:** ของสะสมเสริม กด E เพื่อเก็บ ไม่จำเป็นต่อการผ่านด่าน

การเรียกกลับ checkpoint จะรักษาวงจรที่เปิดสำเร็จไว้และกู้คืนแบตเตอรี่ที่เก็บแล้ว การเริ่มด่านใหม่ด้วย R จะล้างเฉพาะความคืบหน้าด่านปัจจุบันและเติมชีวิตเป็น 5 ด่านก่อนหน้าที่ผ่านแล้วยังคงผ่านอยู่

## ภาพและตัวละคร

โลกและ GUI วาดด้วย Java2D: พื้นโลหะ อุปกรณ์โฮโลแกรม ผนังเรืองแสง สวนอวกาศ แท่นอพยพ แบตเตอรี่ เลเซอร์ แมลงปีศาจ ยานเอเลียน และหุ่นยนต์ศัตรู ไม่ต้องดาวน์โหลด assets ขณะเล่น

- `src/main/resources/sprites/robot-reference.png` — ภาพต้นฉบับจาก PDF อ้างอิง ใช้ในหน้าเมนู
- `src/main/resources/sprites/robot-walk-sheet.png` — ชุดภาพเดินหลายทิศทางจากหุ่นยนต์อ้างอิง สำหรับฉากเล่น

ชุดภาพเดินสร้างด้วยเครื่องมือ `image_gen` ที่มีในระบบ โดยใช้หุ่นยนต์เดิมเป็นภาพอ้างอิง รายละเอียดและ prompt ฉบับเต็มอยู่ใน [ARTWORK.md](src/main/resources/sprites/ARTWORK.md)

หุ่นยนต์ยังคงเกราะเหลือง–ขาวและตาแดง พร้อมภาพเดินสลับเท้า หันตามทิศทาง เงาที่พื้น และจังหวะเคลื่อนไหวตามความเร็ว

## โครงสร้าง OOP

| `Main` | สร้าง JFrame และเริ่มโปรแกรมบน Swing Event Dispatch Thread |

## ตรวจสอบการทำงาน

```sh
./test.command
```

ทดสอบแบบ headless ด้วย Java โดยไม่ต้องเปิดหน้าต่างหรือใช้ framework เพิ่ม ครอบคลุมการเคลื่อนไหว การชน แบตเตอรี่เพียงก้อนเดียว วงจร การผ่านด่านตามลำดับ การออกจากด่าน 2 เมื่อแบตเตอรี่ยังเสียบอยู่ ชีวิตและการพ่ายแพ้ อาวุธและศัตรู จุดปลอดภัย การเริ่มด่านใหม่ และการกดปุ่มค้างขณะเปลี่ยนเมนู

## สร้างไฟล์ JAR

ใช้ JDK 17 ขึ้นไป เปิด Terminal ในโฟลเดอร์นี้แล้วรัน:

```sh
bash build-jar.command
java -jar dist/BorrowedEnergy.jar
```

ไฟล์ JAR รวมรูปที่เกมใช้อยู่แล้ว ต้องมี Java 17 หรือใหม่กว่าบนเครื่องที่เปิดเกม
