# Character artwork

`robot-reference.png` is the original transparent robot image extracted from the supplied reference PDF. The title screen continues to use this image.

`robot-walk-sheet.png` was generated with the built-in `image_gen` tool using `robot-reference.png` as the character identity reference. It supplies 16 walking poses: four directions and four phases. The original generated PNG is preserved; the game detects the complete silhouettes at load time and aligns their helmets and feet for rendering.

Rows: down, left, right, up. Columns: left stride, passing pose, right stride, passing pose. Walking phase is measured in radians and advances with actual distance moved. Movement stops use a passing pose and a subtle idle breathing motion.

## Generation prompt

Use case: stylized-concept. Asset type: production 2D game character walking sprite sheet. Image 1 is the CHARACTER IDENTITY REFERENCE. Create a square transparent PNG sprite sheet in an EXACT 4 column by 4 row grid, 16 equally sized invisible cells. One full-body yellow and ivory chibi robot inside each cell, same character design, same apparent height, feet anchored at the same lower baseline within each cell, complete silhouettes with generous transparent padding. Preserve reference identifying details: oversized gold/yellow helmet and armor, tall red rectangular crest on forehead, red eyes, ivory mechanical face, gold triangular chest guard, black joints, ivory robotic arms and legs, large ivory boots, bold dark outlines. Clean polished 2D hand-drawn cartoon game art with simpler details readable at 54 pixels tall; no weapons. Camera: slightly elevated RPG top-down 3/4 view, feet visible. Exact grid ordering: ROW 1 four sequential walk cycle frames facing DOWN towards viewer; ROW 2 four sequential walk cycle frames facing LEFT; ROW 3 four sequential walk cycle frames facing RIGHT; ROW 4 four sequential walk cycle frames facing UP away from viewer, showing back of helmet and armor, no face visible. Columns for every row are natural alternating stride: 1 left leg forward/right arm forward counter-swing, 2 passing neutral midstep, 3 right leg forward/left arm forward counter-swing, 4 other passing neutral midstep. Body stays same scale and consistent shapes across all cells. No text, no labels, no borders, no grid lines, no shadows, no ground, no scenery, no extra robots outside the 16 cells. Transparent background with real alpha, not checkerboard.
